How it works

One agent drags every file and every failure through one ever-growing conversation. Duelz cuts the job into pieces that each fit in a small prompt.

1FailuresRun the tests. Collect every failure and its traceback.
2Split by causeGroup failures by the source file the traceback bottoms out in. N failures, fewer bugs.
  
3Parallel fixesEach piece gets only its file and its tests. Cheap, short, simultaneous.
  
4VerifyRe-run each piece's tests, retry if red, then the full suite before anything ships.
